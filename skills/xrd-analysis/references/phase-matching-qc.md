# XRD phase-matching QC

Record radiation and wavelength, scan geometry, raw 2θ/intensity, any background subtraction, smoothing, and peak-finding parameters. Use a traceable reference pattern or database ID. Compare multiple expected peaks and relative intensities, including predicted peaks that are absent or obscured.

Account for peak overlap, preferred orientation, strain, finite size, zero shift, and amorphous background. Keep unmatched observed peaks in the report. A single coincident 2θ position supports only a tentative candidate, not a unique phase identification.
