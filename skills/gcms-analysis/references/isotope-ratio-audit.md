# Isotope-channel audit

For each run, retain the TIC peak window, selected scans, exact m/z channels, scan times, raw ion intensities, blank signal, and any correction. Compare standards and blanks using the same window. A ratio such as `I(m+2)/I(m)` is an ion-channel observation, not automatically a molecular isotope fraction: fragmentation, coelution, detector response, natural abundance, and background may change it.

Report raw and corrected ratios separately. State the correction matrix or factor, its source, and uncertainty. If a required reference or blank is missing, report an uncorrected candidate ratio with a QC hold rather than an isotope-origin conclusion.
