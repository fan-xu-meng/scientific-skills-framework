# XPS fit-report QC

Record photon source, analyzer settings, charge reference and shift, background model, fitting window, line shape, sensitivity factors, and excluded regions. Keep raw counts separate from corrected and fitted arrays. For each component, report center, width, area, uncertainty, constraint, and whether it hit a bound.

A peak position is supporting evidence, not a unique oxidation-state assignment. Compare plausible chemical-state models, residual structure, background sensitivity, and spin-orbit relationships. If the carbon reference is uncertain, carry that uncertainty into chemical-shift interpretation and state the limitation.
